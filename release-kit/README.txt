DeskPal Chibi UI · 双主题手游风皮肤 使用说明
==============================================

【安装步骤】
1. 双击「一键安装皮肤.cmd」（脚本会自动检测 DeskPal 安装目录，提示关闭正在运行的 DeskPal 后自动备份原版并重启）。
2. 如未自动检测到目录，直接把 DeskPal 安装文件夹拖进命令行窗口回车即可。

【还原官方原版】
- 随时双击「一键还原原版.cmd」即可完整恢复官方原版界面。

【常见说明】
- 标题栏右上角「月亮 / 太阳」图标：一键切换 奶油手账（浅色）与 星夜大厅（深色）。
- 点击舞台角色 / 换角色按钮 / 任意成员头像：自由为自己和房友指定喜欢的 Q 版 AI 娘或限定皮肤。
- DeskPal 自动更新后，官方会重建 current 目录，更新后再双击一次「一键安装皮肤.cmd」即可。
